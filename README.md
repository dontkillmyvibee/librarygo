# Library

## Authors
Базовый путь API: `/api/v1`.

| Method | Endpoint | Description |
|---|---|---|
| GET | `/authors` | Получить список авторов. Пагинация: `limit` и `offset` |
| GET | `/authors/{id}` | Получить автора по ID |
| POST | `/authors` | Создать автора |
| PATCH | `/authors/{id}` | Частично обновить автора |
| DELETE | `/authors/{id}` | Удалить автора |
